GROWMind Services - Static Website
================================

Files:
- index.html
- style.css
- script.js

Before publishing:
1. Add the official Growmind Services email address in script.js (the mailto currently intentionally has no address because the public search result did not expose a reliable official email).
2. If you have an official phone/WhatsApp number, add it to the Contact section in index.html.
3. Upload all three files to your hosting public_html / root folder.
4. Point growmindservices.com DNS to your hosting provider.

The website is plain HTML/CSS/JS and needs no build process, database, or framework.
